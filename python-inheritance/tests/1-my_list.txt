The ``MyList`` class
=====================

Import the class:

    >>> MyList = __import__('1-my_list').MyList

Create a new list and append some values:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

``print_sorted`` prints the list in ascending order:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list itself is unchanged:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

``print_sorted`` works on an empty list:

    >>> empty_list = MyList()
    >>> empty_list.print_sorted()
    []

``print_sorted`` handles negative numbers correctly:

    >>> neg_list = MyList()
    >>> neg_list.append(-5)
    >>> neg_list.append(3)
    >>> neg_list.append(-1)
    >>> neg_list.append(0)
    >>> neg_list.print_sorted()
    [-5, -1, 0, 3]
